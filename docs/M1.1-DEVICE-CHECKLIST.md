# M1.1 device re-test (about 10 minutes)

What changed: buttons only fire when the note is really on screen; word
readings now outrank single squares (the I→T / K→V false ✗); tap dots on the
buttons are tidied; Mini grid lines are 4 px; READ on probe pages is faster.

1. Install the newest green CI build from `m1-mini` (Artifacts, don't unzip,
   Add Plugin), restart.
2. File manager → New Folder: type with the on-screen keyboard over where TAP
   / REVEAL would be. Nothing should pop up.
3. Open "Mini - sample-1" (Puzzles → Start sample Mini). Erase a few answers
   and write them again in your usual style, including the ones that were
   misread (ALIVE, TOKEN, ALIKE squares), and one deliberate mistake. Tap
   **CHECK**.
   - Only your deliberate mistake should be ✗.
   - The small dots your pen left on CHECK / REVEAL should disappear.
4. Optional: start a fresh Mini to see the 4 px lines: delete
   `Note/SupernotePuzzles/Mini - sample-1.note` first (this loses that
   puzzle's marks), then Puzzles → Start sample Mini.
5. Puzzles → **Write log now**; upload `log.txt` and a photo after step 3.
