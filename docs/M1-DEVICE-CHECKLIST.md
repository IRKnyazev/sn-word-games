# M1 device checklist (Manta, Chauvet 3.31.45)

About 30 minutes. Note the step number for anything odd. Use your finger in
the Puzzles screens. This list has no answers in it: the sample Mini is a
real puzzle to solve (REVEAL is there if you're stuck).

## A. Install

1. GitHub → Actions → the latest green CI run on `m1-mini` → Artifacts →
   download `SupernotePuzzles-v0.1.0-<number>`. Don't unzip it.
2. Copy it to `MyStyle/`, then Settings → Apps → Plugins → **Add Plugin** →
   choose it. Restart the Manta once.

## B. Recognition probe on your old probe note (nothing to rewrite)

3. Open `Note/SupernotePuzzles/Probe 2026-11-27 190927` (the first probe
   note, with your letters on pages 1–3).
4. Page 1: tap **READ**. This now takes about a minute (it reads every
   square twice). Photograph or copy the dialog.
5. Page 2: tap **READ**; note the dialog.
6. Page 3: tap **READ**; note the dialog.

## C. The sample Mini

7. Open any note → **Puzzles** → **Play → Start sample Mini**. A note
   "Mini - sample-1" opens.
8. Look at the page: is the grid sharp, are the clue numbers and clues easy
   to read, is anything under the toolbar?
9. Fill in **three or four entries** with your pen, and make **one letter
   deliberately wrong**. Tap **CHECK**.
   - Expect ✓ in the box of each fully right entry, ✗ for entries with a
     wrong square, a slash in the top-right corner of the wrong square, and
     a dialog saying what was read for the wrong entries.
   - Photograph the page with the marks.
10. Did anything get marked wrong that you wrote correctly (a misread)? If so,
    what did the dialog say it read?
11. Erase the wrong letter, write the right one, tap **CHECK** again. Do the
    old marks disappear and the new ones appear (no doubled ✓/✗)?
12. Press **Undo** once. Does any plugin mark change? (Expected: no; Undo
    only affects your own writing.)
13. Tap **REVEAL**. The Puzzles screen opens on the puzzle.
    - Tap one empty **square** → Reveal → note the letter shown → **Done**.
    - Tap REVEAL again → pick an **entry** (e.g. a Down) → Reveal → **Done**.
    - Do grey triangles appear in the bottom-right corner of those squares?
    - Write the revealed letters in yourself.
14. Finish the puzzle and tap **CHECK**. Expect "Solved!" with the number of
    revealed squares.
15. Toolbar test: move the floating toolbar so it covers **REVEAL**, tap a
    toolbar icon there. Did the Reveal screen open? (It should never reveal
    anything without your confirmation.) Then the same over **CHECK**.
16. Close the note and reopen it. Are the marks still there? Then Puzzles →
    **Start sample Mini** again: it should reopen the same note.
17. Optional: Puzzles → **Play → CHECK this puzzle** (the menu version of
    the CHECK button) on the Mini page.

## D. Send back

18. Puzzles → **Write log now**. Upload `Document/SupernotePuzzles/log.txt`.
19. Photos: the page after step 9, after step 13, and after step 14.
20. Your answers to steps 8, 10, 11, 12, 15 and 16.
